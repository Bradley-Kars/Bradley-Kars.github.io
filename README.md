# Bradley Kars: Portfolio

Personal portfolio and resume, styled to match [karstechsolutions.com](https://karstechsolutions.com).

Plain static site: no build step, no Jekyll theme.

```
index.html
assets/style.css
images/            profile.jpg, favicon.ico, kts-logo-mark.png, certificate images
.nojekyll          tells GitHub Pages to serve files as-is
```

Edit `index.html` and `assets/style.css`, commit, push.
